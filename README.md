# Sigma Health — Phase 0 scaffold

This repository contains a minimal Expo + TypeScript scaffold to start Phase 0 work.

Getting started

Install dependencies:

```bash
npm install
# or
yarn install
```

Run the app (Expo Dev Tools):

```bash
npm start
# or
yarn start
```

Type check:

```bash
npm run typecheck
```
